Important Note
Please follow the KBB outward SOP before sending the device's to RC or DC
  • As per the Article OP1584 before sending the iOS devices like iPad/ iPhone/Watch/iPod to Repair Centre( RC ) or Dispatch Centre ( DC ) Ensure the products are in Activation mode only ( Hello Screen Mode) Refer the image 1.1
    Note: If you don't send it in (*Hello Screen Mode *) activation mode this will be considered as customer data in the device which will lead to compliance Issue
  • Kindly verify the Shipping Address DC or RC / AWB No / Total Boxes / Total Items / Mode of Transport / Tote Id, Tag Id, Carton Box No / E-Way Bill No to be scan by Bar code reader
  • Ensure the Tote’s and Tag’s are not interchanged Refer the image 1.2 Eg: Blue tote with yellow tag to be used only for DC shipments (Carry in Repair Only ), Grey Tote and Grey Tag to be used for RC shipment ( Mail in repair’s only ) and RED tote with yellow tag to be used Battery shipment only for DC (Carry in Repair Only )
  • E-Way bill is required if the amount exceeding ₹50000 and above
  • Separate the KBB standalone battery from all other KBB parts, When shipping expanded batteries (either expanded within a device or a standalone battery for all devices), ship using ground transportation only,( Use RED tote with yellow tag )
  • Maximum 7 Totes / Boxes can be use to create one NRDC
